## 💎 لماذا RASD؟

| التحدي اليومي | حل RASD |
|---------------|---------|
| ملاحظات مبعثرة (ورق/واتساب) تضيع ولا تُتابع | سجل موحد لكل ملاحظة: كاميرا + طابق + وقت + وصف + مرفقات |
| صور وفيديو متناثرة بلا مرجع | **🖼️ معرض موحد** يجمع كل المرفقات مع رابط أصلها مباشرة |
| مشاركة المرفقات بروابط معقدة منتهية الصلاحية | روابط مشاركة **دائمة ونظيفة** + صفحة عرض خاصة بمشغّل |
| تأخر الاعتماد وغموض الحالة | دورة حياة شفافة (مسودة ⇄ منشورة) + حالة المعاينة لحظياً + إشعارات |
| صياغة التقرير اليومي تستهلك وقت الكتّاب | **توليد ذكي** للبيانات النهائية + **اعتماد** بضغطة زر + وثيقة A4 رسمية جاهزة للطباعة |
| تقارير تبدو كصفحات ويب لا كوثائق رسمية | **محرك وثائق موحد**: نفس الـHTML للمعاينة والطباعة والـPDF — بلا أي بيانات تقنية |
| أنظمة لا تعمل على الجوال | **PWA قابل للتثبيت** + تصميم متجاوب + وضع داكن + يعمل على شبكتك المحلية |

## ✨ أبرز القدرات

### 📝 الملاحظات الميدانية

دورة كاملة: مسودة ← قيد المراجعة ← مقبولة/مرفوضة ← إعادة إرسال.

*   تحديث حي صامت للقوائم دون إعادة تحميل
*   وقت الرصد معروض بكل بطاقة، مع فلترة بالحالة والتاريخ والطابق والكاميرا
*   طباعة A4 بمحرك تكوين تحريري يحافظ على الصور والنص معاً

### 🤖 التقارير اليومية الذكية — [التفاصيل الكاملة](./docs/REPORTS.md)

تقرير واحد لكل يوم يُبنى من الملاحظات **المقبولة** فقط، عبر خط إنتاج صارم:

```
ملاحظات مقبولة (نفس اليوم حصراً)
        ↓
التوليد الذكي — Gemini يصوغ FinalReportData فقط (JSON: ملاحظات + توصيات)
        ↓
مراجعة بشرية وتحرير في المحرر — لا شيء يُحفظ تلقائياً
        ↓
الاعتماد — تحقق + تطبيع + حفظ نسخة مرقّمة + توليد HTML
        ↓
وثيقة A4 رسمية واحدة: المعاينة = الطباعة = PDF
```

*   إرفاق الملاحظات بترتيب حر، واليوم الواحد مفروض من السيرفر (أي ملاحظة من يوم آخر مرفوضة ولو بفارق دقيقة) + إعادة ترتيب فورية
*   زر **توليد ذكي**: يصوغ وقائع موجزة بصيغة الماضي من الملاحظات، **ويقرر بنفسه هل تستدعي الحالة توصيات أصلاً** — الملاحظات الروتينية الهادئة تُنتج توصيات فارغة بدل الحشو
*   **حراس جودة تلقائية** ترفض مخرجات مخترَقة: تسرب التوصيات للملاحظات، القوائم المرقمة داخل ملاحظة، صيغ الأوامر، تكرار الوقائع، إخلاءات فارغة — مع رسالة عربية واضحة وإعادة توليد
*   **وثيقة المحرك الموحدة** (`ReportEngine`): ترويسة رسمية + الرقم والتاريخ مرة واحدة + الملاحظات بترقيم عربي هادئ + التوصيات كقائمة حقيقية (وتُخفى تماماً عند غيابها) + كتلة توقيع زاوية صغيرة — **بلا أي أثر للمحرك**: لا أرقام نسخ، لا كثافة تخطيط، لا طوابع تقنية
*   **كثافة ذكية**: المحرك يقدّر أسطر الطباعة ويشدّ التباعد والخط تلقائياً (من ملاحظة واحدة إلى التقارير المزدحمة متعددة الصفحات) مع حد أدنى للقراءة وفواصل صفحات سليمة
*   **النشر محروس**: مستحيل نشر تقرير بمعاينة قديمة — أي تغيير (ملاحظات/ترتيب/توصيات) بعد الاعتماد يجعل النسخة `stale` ويمنع النشر حتى إعادة الاعتماد
*   عند أي عطل يظهر سبب دقيق بالعربية مع كود (`AI_RATE_LIMITED`، `AI_UNAVAILABLE`…) وزر إعادة — لا رسائل مبهمة
*   تنبيه تلقائي للمراقبين عند النشر + سجل مراجعات لكل تقرير

### 🖼️ معرض المرفقات الموحد — [التفاصيل الكاملة](./docs/GALLERY.md)

قلب المنظومة البصري: كل صور وفيديو وصوت الملاحظات **والإرسالات** في صفحة واحدة.

*   🔍 **فلترة ذكية قابلة للطي**: كاميرا · طابق · نوع · تاريخ · ترتيب — مع عدّاد الفلاتر النشطة
*   👁️ **3 أنماط عرض** محفوظة: شبكة · مدمج · قائمة
*   🏷️ **شارة مصدر** على كل مرفق (ملاحظة خضراء / إرسال كهرماني) + رابط مباشر للأصل
*   ⬇️ التنزيل لكتّاب التقارير فقط — المشاهدة للجميع

### 📤 الإرسالات العامة — منفصلة كليًا

إرسال مبسّط (وصف + كتّاب فقط) بفلترة زمنية جاهزة (اليوم/أمس/7 أيام/30 يوم). **القبول يقلب الحالة فقط — الإرسالية لا تتحول لملاحظة أبدًا.**

### 💬 مشاركة واتساب حقيقية

*   مشاركة لمنتقي جهات الاتصال (لا لشخص مفروض) + نسخ يعمل حتى على HTTP
*   روابط دائمة قصيرة `/s/...` تتكيف تلقائيًا مع عنوان سيرفرك
*   صفحة عرض خاصة بمشغّل صورة/فيديو/صوت — الدخول إجباري، والتنزيل للكتّاب فقط

### 🔔 إشعارات لا تفوّت شيئًا

مركز إشعارات بدرج جانبي + أصوات + عدّاد + إخفاء ذكي عند الفراغ — لحظية مع احتياطي تلقائي.

### 🦅 هوية بصرية رسمية

شعار نسر ذهبي **Vector خالص (SVG)** يتوسع بلا حدود + صفحة دخول مركزية فاخرة + عربي RTL كامل + وضع داكن.

## 🔄 سير العمل

```
ملاحظة:    مسودة ─→ قيد المراجعة ─→ مقبولة ✅ | مرفوضة ─→ إعادة إرسال
إرسالية:   وصف + كتّاب ─→ قيد المراجعة ─→ مقبولة ✅ | مرفوضة (تبقى إرسالية)
تقرير:     مسودة ⇄ منشورة (النشر يشترط: ملاحظة + معاينة معتمدة غير قديمة)
```

## 🧱 الثقة التقنية والتشغيل

*   **Laravel 13 + PHP 8.4** — خدمات مفصولة (`NoteService`، `GeneralSubmissionService`، `ReportService`، `ReportEngine`، `ReportHtmlRenderingService`) وسياسات تفويض صارمة بلا منطق مكرر
*   **فصل صارم**: المحتوى الرسمي في الوثيقة، وبيانات المحرك (`generation_id`، الكثافة، القوالب) في قاعدة البيانات والسجلات فقط
*   **أمان:** JWT للـ API + CSRF للويب + فحص `finfo` للمرفقات + رفض الامتدادات الخطرة + مفتاح Gemini على الخادم فقط
*   **أداء:** بناء Vite + تخزين محلي سريع
*   **يعمل على شبكتك:** LAN + PWA — بلا سحابة وبلا اشتراكات (الذكاء الاصطناعي اختياري عبر الخطة المجانية)
*   **تشغيلياً:** كل توليد موثّق في سجل النظام (`[HTML-RENDER]`/`[REPORT]`)، ونسخ الاعتماد مرقّمة لكل تقرير كسجل تدقيق

## 🚀 التشغيل خلال 5 دقائق

### المتطلبات

`PHP 8.4+` · `Composer` · `MySQL 8+` أو `SQLite` · `Node.js 20+` (لبناء الواجهة)

### الخطوات

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --force
php artisan db:seed
npm install && npm run build
php artisan serve --host=0.0.0.0 --port=8000
```

الدخول التجريبي (كلمة المرور `password` للجميع): `tariq` · `hadi` · `hamza` · `rami` (مراقبون) · `writer` (كاتب تقارير)

> للجوال على نفس الواي فاي + مشاركة واتساب: راجع [`DEVELOPMENT.md`](./docs/DEVELOPMENT.md) (جدار ناري + `SHARE_URL`)
>
> لتفعيل التوليد الذكي للتقارير: مفتاح مجاني من [Google AI Studio](https://aistudio.google.com) ثم ضعه في `.env`:
>
> ```env
> AI_ENABLED=true
> GEMINI_API_KEY=ضع_مفتاحك_هنا
> ```
>
> التفاصيل والأعطال في [`REPORTS.md`](./docs/REPORTS.md)

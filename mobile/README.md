# تطبيق رصد — Flutter

تطبيق أندرويد لنظام رصد (ملاحظات الكاميرات)، مبني على نفس الـAPI الخاص
بالواجهة الويب (`/api` باستخدام JWT Bearer).

## المزايا (مطابقة للويب)

- تسجيل دخول/خروج + حفظ الجلسة (Secure Storage)
- الملاحظات: قائمة بتبويبات الحالة + فلتر (تاريخ/طابق/كاميرا)، ملاحظاتي،
  إنشاء مع مرفقات (صور/فيديو/صوت + كاميرا صور وفيديو + **تسجيل صوتي
  داخل التطبيق**)، تفاصيل مع عرض/طلب الترجمة، إرسال/إعادة/قبول/رفض — حسب الدور والمالك
- الإرساليات العامة: قائمة، إنشاء مع اختيار الكتّاب المستلمين ومرفقات،
  إرسال، قبول/رفض
- التقارير: قائمة، إنشاء، تفاصيل، نشر/سحب، إرفاق ملاحظات مقبولة، إزالة،
  **توليد ذكي AI**، **عرض المستند الرسمي + مشاركته PDF + طباعته**
- مؤشرات التقارير: صحة الأداء، نسب النشر والقبول، التنبيهات التشغيلية
  والنشاط اليومي للفترة المختارة
- المشاركة الموحدة (حسب السماحية): واتساب / تلغرام (نص ورابط) أو مشاركة
  عامة (نص + الوسائط) — للملاحظات والإرساليات والتقارير والمعرض، مع رابط
  السيرفر في البطاقة
- المعرض: شبكة حسب النوع مع عرض الصور (بمصادقة) + مشاركة الملفات
- الإشعارات: polling كل دقيقة + **صوت واهتزاز وتنبيه فوري** + شارة عدد
- الترتيب: قائمة المراقبين وإحصائيات عامة (من الحساب)
- عربي (افتراضي، RTL) / إنجليزي + فاتح/داكن/نظام
- عنوان السيرفر قابل للتغيير من شاشة الدخول أو الحساب

> endpoints أضيفت للباك-إند لخدمة التطبيق:
> `GET /api/users/writers` ،`GET /api/ranking` ،`GET /api/reports/{id}/document`،
> `GET /api/reports/insights`، ومسارات حالة/إعادة طلب ترجمة الملاحظة.

## التشغيل

```bash
cd mobile
flutter pub get
# العنوان الافتراضي: http://10.150.1.103:8000
flutter run --dart-define RASD_BASE_URL=http://10.150.1.103:8000
```

## بناء APK

```bash
flutter build apk --debug        # نسخة تجريبية
flutter build apk --release      # نسخة نهائية
```

> ملاحظة بيئة التطوير: الـGradle مضبوط على JDK 17 محمول في
> `~/.jdks` عبر `android/gradle.properties` (`org.gradle.java.home`).
> عدّل المسار إذا نقلت المشروع لجهاز آخر.

## ملاحظات تقنية

- `android:usesCleartextTraffic="true"` مفعّل لأن السيرفر HTTP داخلي.
- الإشعارات عبر polling (نفس فلسفة الويب) + تسجيل رمز جهاز في
  `POST /api/devices/register`. لإضافة FCM حقيقي لاحقاً: أضف
  `firebase_messaging` مع `google-services.json` وأرسل الـFCM token
  لنفس الـendpoint.
- الأدوار: المدير العام لا يرى تبويب الملاحظات (الـAPI يمنعها).

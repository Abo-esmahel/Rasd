# SYSTEM.md - نظام ملاحظات كاميرات المراقبة

## الغرض
نظام داخلي لوزارة الإعلام لمتابعة كاميرات المراقبة وتسجيل ملاحظات المراقبين واعتمادها.

## النطاق
- تسجيل ملاحظات المراقبة (طابق، كاميرا، تاريخ، وصف، مرفقات)
- تدفق عمل: مسودة → قيد المراجعة → مقبولة/مرفوضة
- إعادة إرسال الملاحظات المرفوضة
- **الإرسالات العامة**: إرسال مبسّط (وصف + كتّاب) بقبول/رفض — منفصلة كليًا عن الملاحظات (القبول لا ينشئ ملاحظة)
- **معرض موحد** لكل المرفقات (ملاحظات + إرسالات) مع فلترة و3 أنماط عرض — راجع `GALLERY.md`
- مشاركة واتساب بروابط دائمة + صفحة عرض خاصة (الدخول إجباري، التنزيل للكتّاب فقط)
- واجهة ويب عربية RTL + وضع داكن
- واجهة برمجة تطبيقات REST لتطبيق Flutter مستقبلي
- **التقارير اليومية**: تقرير واحد لكل يوم من الملاحظات المقبولة، مع توليد مسودة صياغة عبر Gemini — راجع `REPORTS.md`

## المستخدمون والأدوار

### مُراقب (monitor)
- إنشاء مسودات ملاحظات
- عرض/تعديل/حذف مسوداته
- إرسال مسوداته
- عرض جميع الملاحظات (عدا مسودات الآخرين)
- تعديل ملاحظاته قيد المراجعة والمرفوضة
- إعادة إرسال ملاحظاته المرفوضة

### كاتب تقارير (report_writer)
- عرض جميع الملاحظات (عدا المسودات)
- قبول الملاحظات قيد المراجعة
- رفض الملاحظات قيد المراجعة (بسبب إجباري)
- **تنزيل المرفقات (حصريًا)** — المراقب مشاهدة فقط
- إنشاء التقارير اليومية وإدارة تقاريره (توليد مسودة AI، نشر، سحب نشر) — التفاصيل في `REPORTS.md`

## الملكية
`user_id` = ملكية، وليس رؤية
المستخدم المُصادق يملك الملاحظة.
لا يمكن للعملاء التحكم في `user_id`.

## الرؤية
| الحالة   | المُراقب (مالك) | مُراقب آخر | كاتب التقارير |
|----------|-----------------|------------|---------------|
| مسودة    | يعرض            | لا يعرض    | لا يعرض       |
| قيد المراجعة | يعرض        | يعرض       | يعرض          |
| مرفوضة  | يعرض            | يعرض       | يعرض          |
| مقبولة  | يعرض            | يعرض       | يعرض          |

## رؤية التقارير

| التقرير | مُراقب | كاتب التقارير |
|---------|--------|---------------|
| مسودة | لا يعرض | يعرض الكل |
| منشور + مرئي للمراقبين | يعرض (بدون مسودة AI ولا سجل المراجعات) | يعرض الكل |
| منشور + مخفي | لا يعرض | يعرض الكل |
